# Datapilot — 智能文档知识库问答平台

Datapilot 是一个面向企业与个人的智能文档知识库平台。你可以把 PDF 等文档上传入库，系统会自动解析、整理并建立索引；之后通过内置的智能对话助手，直接基于知识库内容回答问题，让「查文档、找答案」变得简单高效。

## ✨ 核心功能

- **文档入库**：上传 PDF 文档，自动完成解析、切分、摘要生成并建立索引
- **智能问答**：基于知识库的对话助手，回答有依据、可追溯
- **精准检索**：融合多种检索方式，从海量文档中快速定位相关内容
- **语义缓存**：相似问题直接命中缓存，响应更快、成本更低
- **用户与权限**：完整的注册登录与角色权限管理，安全可控
- **系统管理**：仪表盘数据概览、数据库查看、系统设置等一应俱全

## 🧩 系统组成

```
┌─────────────────────────────────────────────────────────┐
│                    浏览器（Web 管理端）                    │
│        仪表盘 · 智能对话 · 用户权限 · 系统设置             │
└─────────────────────────┬───────────────────────────────┘
                          │
          ┌───────────────┼───────────────┐
          ▼               ▼               ▼
      核心服务          文档处理服务       检索问答服务
    用户 · 权限      解析 · 入库 · 建索引    检索 · 生成回答
    数据库管理
          │               │               │
          └───────────────┼───────────────┘
                          ▼
               数据库 · 向量库 · 缓存
```

- **Web 管理端**：浏览器访问的操作界面，涵盖数据概览、知识库问答、用户与权限管理等
- **核心服务**：提供用户、权限、数据库管理等基础能力
- **文档处理服务**：负责 PDF 解析与知识库入库，让文档变成可检索的内容
- **检索问答服务**：负责知识检索与答案生成，是智能问答的核心引擎

## 🚀 快速开始

### 开发环境

各服务分别启动：

| 服务 | 目录 | 启动方式 |
|------|------|----------|
| Web 管理端 | `client/` | `npm run dev` |
| 核心服务 | `services/core/` | `npm run dev` |
| 文档处理服务 | `services/doc-kit/` | 见 [doc-kit/README.md](services/doc-kit/README.md) |
| 检索问答服务 | `services/docs-seeker/` | 见 [docs-seeker/README.md](services/docs-seeker/README.md) |

详细步骤参见 [DEVELOPMENT.md](DEVELOPMENT.md)。

### 生产部署

进入 `deploy/` 目录，配置好环境变量后一条命令即可完成全部服务的部署，详见 [deploy/README.md](deploy/README.md)。

## 📁 目录结构

```
datapilot/
├── client/          # Web 管理端（前端界面）
├── services/        # 后端服务集合
│   ├── core/        # 核心服务（用户、权限、数据库管理）
│   ├── doc-kit/     # 文档处理服务（解析、入库）
│   └── docs-seeker/ # 检索问答服务（RAG 智能问答）
├── deploy/          # 一键部署（Docker Compose）
├── scripts/         # 开发辅助脚本
└── DEVELOPMENT.md   # 开发环境指南
```
